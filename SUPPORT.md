# Support

## Project support

Open a GitHub issue for setup questions, reproducible defects, and feature proposals:

https://github.com/Brajesh31/car-rental-vue-laravel-app/issues

Include the affected route or component, reproduction steps, expected and observed behavior, PHP/Node/database versions, and sanitized error messages. Do not attach database dumps, user records, session data, passwords, tokens, or private customer details.

For a security vulnerability, use the private process in SECURITY.md instead of a public issue.

## Project scope

This repository is a Laravel/Inertia/Vue car-rental application. Features include account forms, car management, rental records, and booking email scaffolding. Some behaviors are incomplete and identified in README.md and docs. There is no paid support service or guarantee that the current repository is ready for production use.

## Response expectations

The project is maintained by Brajesh Kumar (@brajesh31). There is no guaranteed response time. Please follow CODE_OF_CONDUCT.md.
