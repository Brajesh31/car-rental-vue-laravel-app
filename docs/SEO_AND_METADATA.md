# 🔎 SEO and Metadata

## Public pages
Use unique descriptive titles and meta descriptions for indexable public pages. Provide canonical URLs and social preview metadata where appropriate.

## Private pages
Authentication-required dashboards, rental details and account pages should not be indexed. Avoid exposing customer names, booking dates or other private details in metadata.

## Technical checks
- Verify robots directives and sitemap contain only intended public URLs.
- Ensure canonical URLs use the production host and HTTPS.
- Provide descriptive link text and image alt text.
- Avoid duplicate titles and empty metadata.
- Confirm error pages do not expose debug details.

## Release checks
Inspect rendered HTML, page titles, canonical links, robots behavior and social previews after deployment.
