# ♿ Accessibility Statement

The project aims to make its public and authenticated interfaces usable by people with different access needs. The engineering target is WCAG 2.2 AA; no independent audit or conformance certification is claimed by this statement.

## Known approach
The repository includes accessibility guidance and review templates. Actual conformance must be assessed against the rendered application.

## Feedback
Report barriers through the repository issue tracker using the accessibility issue context. Do not include sensitive account or rental data.

## Improvement process
Reports should include affected route/component, assistive technology, browser, steps to reproduce and expected behavior. Maintainers should prioritize barriers that prevent core tasks such as registration, sign-in, vehicle discovery and booking.
